core rule		3.6.0 beta: Targets get -X to Defense rolls when blocking hits.

✏️Ranged Shrouding3.6.0 beta: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -4"" range to a min. of 6" when shooting at it.
3.6.0: When a unit where most models have this rule is targeted by an enemy unit for shooting, that enemy unit gets -4" range to a min. of 6".
✏️Scourge3.6.0 beta: For each unmodified result of 1 to block hits, this weapon counts as having dealt 2 extra wounds when checking who won melee, or if shooting wounds would trigger Morale Tests.
3.6.0: For each unmodified result of 1 to block hits, enemies count as having taken 2 extra wounds when checking who won melee, or if shooting wounds would trigger Morale Tests.
✏️Shred when Shooting Aura3.6.0 beta: This model's unit and up to 2 nearest friendly units picked before the start of the game get Shred when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Shred on its weapons when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Versatile Defense3.6.0 beta: As long as a unit where most models have this rule hasn't activated yet this round, pick one effect when it is attacked: the unit either gets +1 to Defense rolls, or enemy units get -1 to hit rolls against it. Note that you may pick a different effect each time the unit is attacked.
3.6.0: When a unit where most models have this rule is shot/charged from over 9"/6" away, pick one effect: the unit either gets +1 to Defense rolls, or enemy units get -1 to hit rolls against it. Note that you may pick a different effect each time the unit is attacked.
