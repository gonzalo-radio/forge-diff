✏️Counter in Melee Aura3.6.0 beta: This model's unit and up to 2 friendly units picked before the start of the game get Counter in melee. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Counter on its weapons in melee. If this model is killed, picked models that are deployed lose the rule.
✏️Piercing Spotter3.6.0 beta: Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. When attacking, friendly units may remove tokens from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed tokens.
3.6.0: Once per activation, before attacking, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. When attacking, friendly units may remove tokens from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed tokens.
✏️Rending when Shooting Aura3.6.0 beta: This model's unit and up to 2 friendly units picked before the start of the game get Rending when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Rending on its weapons when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Shred in Melee Aura3.6.0 beta: This model's unit and up to 2 friendly units picked before the start of the game get Shred in melee. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Shred on its weapons in melee. If this model is killed, picked models that are deployed lose the rule.
✏️Spell Resistance3.6.0 beta: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. If the wound was from a spell, then it is ignored on a 2+. If the wound was not from a spell, then it is ignored on a 6+ instead.
✏️Versatile Reach3.6.0 beta: When this unit is activated, pick one effect: until the end of the activation, when attacking enemies that already finished an activation this round, all models with this rule in this unit either get +4" range when shooting or move +2" when charging.
3.6.0: When this unit is activated, pick one effect: until the end of the activation, all models with this rule in this unit either get +4" range when shooting or move +2" when charging.
