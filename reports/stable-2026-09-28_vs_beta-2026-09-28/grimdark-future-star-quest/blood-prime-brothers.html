Special rules

NameText
➕Bravery AuraThis model's unit and up to 2 friendly units picked before the start of the game get +1 to Morale Test rolls. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced BloodbornIf this model has Bloodborn, it gets extra attacks on successful unmodified hit results of 5-6 from Bloodborn (instead of only on 6).
➕Enhanced PredatorIf this model has Predator, it gets extra attacks on successful unmodified hit results of 5-6 from Predator (instead of only on 6).
➕PierceIgnores Cover, and when attacking units over half of this weapon's range away, this weapon gets AP(+1).
➕Versatile ExpertWhen this unit is activated, pick one effect: until the end of the activation all models with this rule in this unit either get AP(+1) when attacking, or get +1 to hit rolls when attacking.
➖Courage AuraThis model and up to 3 friendly units picked before the start of the game get +1 to morale test rolls. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖Piercing AssaultThis model gets AP(+1) when charging.
➖ShatterAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+2).
➖ShieldedUnits where all models have this rule get +1 to defense rolls against hits that are not from spells.
➖Versatile AttackWhen this unit is activated, pick one effect: until the end of the activation, when shooting or charging enemies over 9" away, all models with this rule in this unit either get AP(+1) or get +1 to hit rolls.
✏️Evasive3.5.1: Enemies get -1 to hit rolls when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls when attacking units where most models have this rule.
✏️Melee Shrouding3.5.1: Enemies get -3" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -2" range to a min. of 6" when charging it.
✏️Ravage3.5.1: When it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
3.6.0: Once per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Shred
becomes a core rule		3.5.1: On unmodified results of 1 to block hits, this weapon deals 1 extra wound.
3.6.0: For each unmodified result of 1 to block hits, this weapon deals 1 extra wound.
✏️Unstoppable
core rule		3.5.1: Ignores Regeneration, and ignores all negative modifiers to this weapon.
3.6.0: Ignores Regeneration, and ignores all negative modifiers to this weapon which are not from this model's special rules.
✏️Unstoppable Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Unstoppable against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Unstoppable against once (next time the effect would apply).
✏️Versatile Reach3.5.1: When this unit is activated, pick one effect: until the end of the activation all models with this rule in it either get +4" range when shooting, or move +2" when charging.
3.6.0: When this unit is activated, pick one effect: until the end of the activation, when attacking enemies for the first time each round, all models with this rule in this unit either get +4" range when shooting or move +2" when charging.
✏️Versatile Reach Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Versatile Reach. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Versatile Reach. If this model is killed, picked models that are deployed lose the rule.
