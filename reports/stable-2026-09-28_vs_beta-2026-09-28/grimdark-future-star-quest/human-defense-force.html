✏️Entrenched
no longer a core rule		3.5.1: As long as a unit where all models have this rule hasn't moved during the round, enemy units shooting at it from over 9" away get -2 to hit rolls.
3.6.0: If most models in this unit have this rule, as long as they haven't moved during this round, enemy units shooting at them from over 12” away get -1 to hit rolls.
✏️Entrenched Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets Entrenched once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets Entrenched once (next time the effect would apply).
✏️Hero
core rule		3.5.1: Friendly units within 12” may take morale tests using the hero’s Quality, as long as the hero isn’t Shaken.
3.6.0: Units within 6” of friendly Heroes may use the Hero’s Quality for Morale Tests as long as the Hero isn’t Shaken.
✏️Hold the Line3.5.1: Units where all models have this rule get +1 to morale test rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, they get +1 to Morale Test rolls.
✏️Martial Prowess3.5.1: Once per game, if all models in this unit have this rule, it may be activated even if it had already activated this round (stops being fatigued when activated for the second time). Only up to one third of the units in the army with this rule at the beginning of the game (rounding up) may use it in a single round.
3.6.0: Once per game, if all models in this unit have this rule, it may be activated even if it had already activated this round (stops being Fatigued when activated again). Only up to one third of the units in the army with this rule at the beginning of the game (rounding up) may use it in a single round.
✏️Morale Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which gets -1 to morale test rolls once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which gets -1 to Morale Test rolls once (next time the effect would apply).
✏️Precision Shooter Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls when shooting once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls when shooting once (next time the effect would apply).
✏️Rapid Advance Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets Rapid Advance once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets Rapid Advance once (next time the effect would apply).
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Relentless
core rule		3.5.1: When this model shoots at enemies over 9" away, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model shoots at enemies over 9” away, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Relentless Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Relentless against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Relentless against once (next time the effect would apply).
