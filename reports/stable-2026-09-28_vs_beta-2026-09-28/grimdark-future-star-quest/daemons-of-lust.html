NameText

➕ObliterateIgnores Regeneration, and when attacking units where most models have Tough(27) or higher, the target must re-roll successful unmodified Defense results of 5-6.
➕Piercing ChargeThis model gets AP(+1) when charging.
➕Unpredictable FighterWhen in melee, roll one die and apply one effect to all models with this rule: on a 1-3 they get AP(+1), and on a 4-6 they get +1 to hit rolls instead.
➖Counter-AttackStrikes first when charged.
➖Lustbound BoostIf this model has Lustbound, it gets +8" range when shooting and moves +4" when using Charge actions from Lustbound (instead of only +4" and +2").
➖Piercing AssaultThis model gets AP(+1) when charging.
➖Reach HuntThis model gets +4" range when shooting and moves +2" when using Charge actions.
➖ShatterAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+2).
➖Storm of LustOnly one use per game. Once per game, when this model is activated, before attacking, roll 3 dice. For each 2+ one enemy unit within 12" takes 3 hits with Surge (roll one die per hit to see if it triggers).
➖SurgeOn unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
✏️Hit & Run Fighter3.5.1: Once per round, units where all models have this rule may move by up to 3" after being in melee.
3.6.0: Once per round, this model may move by up to 3" after being in melee.
✏️Lustbound3.5.1: This model gets +4" range when shooting and moves +2" when using Charge actions.
3.6.0: Moves +1" when using Advance, and +2" when using Rush/Charge.
✏️Melee Evasion3.5.1: Enemies get -1 to hit rolls in melee when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls in melee when attacking units where most models have this rule.
✏️Mind Control3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which must take a morale test. If failed you may move it by up to 6" in a straight line in any direction.
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which must take a Morale Test. If failed you may move it by up to 6" in a straight line in any direction. Units may only be moved once per round in this way.
✏️Quick Shot Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Quick Shot against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Quick Shot against once (next time the effect would apply).
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Shred
becomes a core rule		3.5.1: On unmodified results of 1 to block hits, this weapon deals 1 extra wound.
3.6.0: For each unmodified result of 1 to block hits, this weapon deals 1 extra wound.
✏️Strider
core rule		3.5.1: May ignore the effects of difficult terrain when moving, and only needs 2+ to pass jumping rolls.
3.6.0: May ignore the effects of Difficult terrain. This unit halves the number of dice it rolls when jumping (rounding up).
✏️Strider Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Strider. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Strider. If this model is killed, picked models that are deployed lose the rule.
✏️Unstoppable
core rule		3.5.1: Ignores Regeneration, and ignores all negative modifiers to this weapon.
3.6.0: Ignores Regeneration, and ignores all negative modifiers to this weapon which are not from this model's special rules.
