Special rules

NameText
➕ScourgeFor each unmodified result of 1 to block hits, this weapon counts as having dealt 2 extra wounds when checking who won melee, or if shooting wounds would trigger Morale Tests.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
✏️Brute Courage3.5.1: If a unit where all models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
3.6.0: If a unit where most models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
✏️Fearless
core rule		3.5.1: When a unit where all models have this rule fails a morale test, roll one die. On a 4+ it counts as passed instead.
3.6.0: When a unit where most models have this rule fails a Morale Test, roll one die. On a 4+ it counts as passed instead.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Precision Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which gets -1 to hit rolls when attacking once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which gets -1 to hit rolls when attacking once (next time the effect would apply).
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Steadfast3.5.1: If a unit where all models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
3.6.0: If a unit where most models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
✏️Surge
becomes a core rule		3.5.1: On unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
3.6.0: For each unmodified result of 6 to hit, this weapon deals 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Versatile Defense3.5.1: When a unit where all models have this rule is deployed or activated, pick one effect: when shot or charged from over 9" away, the unit either gets +1 to defense rolls, or enemy units get -1 to hit rolls against it. This effect lasts until the units' next activation.
3.6.0: As long as a unit where most models have this rule hasn't activated yet this round, pick one effect when it is attacked: the unit either gets +1 to Defense rolls, or enemy units get -1 to hit rolls against it. Note that you may pick a different effect each time the unit is attacked.
✏️Versatile Defense Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule.
