Special rules

NameText
➕Enhanced HavocboundIf this model has Havocbound, it always gets AP(+1) from Havocbound (instead of only when attacking enemies that already finished an activation).
➕Enhanced Havocbound AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Havocbound. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced Piercing WarriorIf this model has Piercing Warrior, it always gets AP(+1) from Piercing Warrior (instead of only when attacking enemies that already finished an activation).
➕Piercing MarksmanWhen shooting at enemies over 9" away, this model's weapons get AP(+1).
➕PurgeWhen attacking units that are Shaken or Fatigued, this weapon gets AP(+2).
