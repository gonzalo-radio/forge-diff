Special rules

NameText
➕Crossing AttackOnce per activation, when this model moves through enemy units, pick one of them and roll X dice. For each 6+ the target takes one wound.
➕Enhanced MischievousIf this model has Mischievous, enemies taking hits from it must re-roll successful unmodified Defense results of 5-6 from Mischievous (instead of only results of 6).
➕Enhanced Mischievous AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Mischievous. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced ViciousIf this model has Vicious, enemies taking hits from it must re-roll successful unmodified Defense results of 5-6 from Vicious (instead of only results of 6).
➕HazardousGets AP(4), but on unmodified results of 1 to hit this model takes one wound, or X wounds if this weapon has the Blast(X)/Deadly(X) rule.
➖Mischievous BoostIf this model has Mischievous, when it shoots or charges enemies over 9" away, enemies taking hits from it must re-roll successful unmodified defense results of 5-6 from Mischievous (instead of only on 6).
➖Mischievous Boost AuraThis model and up to 3 friendly units picked before the start of the game get Mischievous Boost. If this model is killed, picked models that are deployed lose the rule.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖StrafingOnce per activation, when this model moves through enemy units, pick one of them and attack it with this weapon as if it was shooting. This weapon may only be used in this way.
➖TearAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+4).
✏️Bounding3.5.1: When this unit is activated, you may place all models with this rule in it anywhere fully within D3+1" of their position.
3.6.0: When this unit is activated, you may move all models with this rule in it by up to D3+1".
✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Models within 18” in line of sight of the caster’s unit may spend any number of spell tokens at the same time before rolling, to give the caster +1/-1 to the roll per token.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Models within 18” of the Caster may spend any number of spell tokens at the same time before rolling to give the Caster +1/-1 to the roll per token.
✏️Melee Evasion3.5.1: Enemies get -1 to hit rolls in melee when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls in melee when attacking units where most models have this rule.
✏️Melee Evasion Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Melee Evasion. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Melee Evasion. If this model is killed, picked models that are deployed lose the rule.
✏️Precision Fighter Buff3.5.1: Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
3.6.0: Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
✏️Quick Shot Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Quick Shot. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Quick Shot. If this model is killed, picked models that are deployed lose the rule.
✏️Rapid Charge Aura3.5.1: This model and up to 3 friendly units picked before the start of the game moves +4" when using Charge actions. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game moves +4" when using Charge actions. If this model is killed, picked models that are deployed lose the rule.
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Takedown
core rule		3.5.1: This model may pick any model in the target unit as its individual target, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
3.6.0: This model may pick any model in the target unit as its individual target for this weapon's attacks, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
✏️Takedown Strike3.5.1: Once per game, when it's this model's turn to attack in melee, it may make one attack at Quality 2+ with AP(2), Deadly(3), and Takedown.
3.6.0: Once per game, when it's this model's turn to strike in melee, it may make X attacks at Quality 2+ with AP(2), Deadly(3), and Takedown.
✏️Thrust in Melee Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Thrust in melee. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Thrust in melee. If this model is killed, picked models that are deployed lose the rule.
