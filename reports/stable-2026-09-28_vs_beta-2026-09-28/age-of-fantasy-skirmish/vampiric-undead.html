➕Enhanced Cursed UndeadIf most models in this unit have Cursed Undead, they ignore wounds on rolls of 5-6 from Cursed Undead (instead of only on 6+).
➕Enhanced Cursed Undead BuffOnce per activation, before attacking, pick up to 3 friendly units within 12", which gets Enhanced Cursed Undead once (next time the effect would apply).
➕Enhanced ProtectedIf most models in this unit have Protected, they ignore wounds on rolls of 5-6 from Protected (instead of only on 6+).
➕FragmentWhen attacking units where most models have Defense 4+ to Defense 6+, the target must re-roll successful unmodified Defense results of 4-6.
➕Piercing MarksmanWhen shooting at enemies over 9" away, this model's weapons get AP(+1).
➕Piercing Marksman AuraThis model's unit and up to 2 friendly units picked before the start of the game get Piercing Marksman. If this model is killed, picked models that are deployed lose the rule.
➕Unique HeroCounts as having Hero, and this model may only be taken once per army.
➖Cursed Undead BoostIf all models in this unit have Cursed Undead, they ignore wounds on rolls of 5-6 from Cursed Undead (instead of only on 6+).
➖Cursed Undead Boost BuffOnce per activation, before attacking, pick up to 4 friendly units within 12", which gets Cursed Undead Boost once (next time the effect would apply).
➖DisintegrateIgnores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➖Piercing HunterWhen this model shoots at enemies over 9" away, its weapons get AP(+1).

✏️Cursed Undead3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Fast Aura3.5.1: This model and up to 3 friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
✏️Mind Control3.5.1: Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which must take a morale test. If failed you may move it by up to 6" in a straight line in any direction.
3.6.0: Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which must take a Morale Test. If failed you may move it by up to 6" in a straight line in any direction. Units may only be moved once per round in this way.
✏️No Retreat3.5.1: Whenever a unit where most models have this rule fails a morale test that causes it to be Shaken or Routed, the test counts as passed instead. Then, roll as many dice as the number of wounds it would take to check for wound effects (must always roll at least 1 die), and for each result of 1-3 the unit takes one wound, which can't be ignored.
3.6.0: When a unit where most models have this rule fails a Morale Test that causes it to be Shaken or Routed, the test counts as passed instead. Then, roll as many dice as the number of wounds it would take to fully destroy it, and for each result of 1-3 the unit takes one wound, which can't be ignored.
✏️No Retreat Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get No Retreat. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get No Retreat. If this model is killed, picked models that are deployed lose the rule.
✏️Protected3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Ravage3.5.1: When it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
3.6.0: Once per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
✏️Reanimation Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Reanimation. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Reanimation. If this model is killed, picked models that are deployed lose the rule.

core rule		3.5.1: May be set aside before deployment. After all other units are deployed, may be deployed anywhere fully within 12” of their deployment zone. Players alternate in placing Scout units, starting with the player that activates next.
3.6.0: May be set aside before deployment. After all other units are deployed, may be deployed anywhere fully within 9” of their deployment zone, over 9” away from non-Scout enemy units. Players alternate in placing Scout units, starting with the player that activates next.

3.6.0: When units where most models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
