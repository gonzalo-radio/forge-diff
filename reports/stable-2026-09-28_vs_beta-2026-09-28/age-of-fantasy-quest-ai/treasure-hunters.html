Special rules

NameText
➕AgileMoves +1" when using Advance, and +2" when using Rush/Charge.
➕Bravery AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get +1 to Morale Test rolls. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced AgileIf this model has Agile, it moves +2" on Advance and +4" on Rush/Charge from Agile (instead of only +1" and +2").
➕Enhanced RunnerIf this model has Runner, it moves +2" on Advance and +4" on Rush/Charge from Runner (instead of only +1" and +2").
➕Enhanced Runner AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Enhanced Runner. If this model is killed, picked models that are deployed lose the rule.
➕FractureFor each unmodified result of 6 to hit, those hits get AP(+2).
➕Precision SpotterOnce per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. Friendly units may remove tokens from their target before rolling to hit to get +X to hit rolls when attacking, where X is the number of removed tokens.
➖Courage AuraThis model and up to 3 nearest friendly units picked before the start of the game get +1 to morale test rolls. If this model is killed, picked models that are deployed lose the rule.
➖CrackOn unmodified results of 6 to hit, those hits get AP(+2).
➖Piercing SpotterOnce per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a marker on it. When attacking, friendly units may remove markers from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed markers.
➖QuickMoves +2" when using Advance, and +2” when using Rush/Charge.
➖Runner BoostIf this model has Runner, it moves +4" on Advance and +4" on Rush/Charge from Runner (instead of only +2" and +2").
➖Runner Boost AuraThis model and up to 3 nearest friendly units picked before the start of the game get Runner Boost. If this model is killed, picked models that are deployed lose the rule.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
✏️Ambush
core rule		3.5.1: Only deploys D3 rounds afters its wave is deployed, and at the start of the round it's placed at the centre of a random table quarter.
3.6.0: Only deploys D3 rounds afters its wave, and at the start of the round it's placed within 6” of a random AI Goal.
✏️Furious
core rule		3.5.1: When charging, unmodified results of 6 to hit in melee deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When charging, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Furious Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
✏️Melee Shrouding3.5.1: Enemies get -3" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -2" range to a min. of 6" when charging it.
✏️Melee Shrouding Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Melee Shrouding. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Melee Shrouding. If this model is killed, picked models that are deployed lose the rule.
✏️Precision Fighting Mark3.5.1: Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
3.6.0: Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
✏️Relentless
core rule		3.5.1: When this model shoots at enemies over 9" away, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model shoots at enemies over 9” away, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Relentless Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Relentless. If this model is killed, picked models that are deployed lose the rule.
