Special rules

NameText
➕Piercing ChargeThis model gets AP(+1) when charging.
➕Piercing Charge AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Piercing Charge. If this model is killed, picked models that are deployed lose the rule.
➕Piercing MarksmanWhen shooting at enemies over 9" away, this model's weapons get AP(+1).
➕Piercing Marksman AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Piercing Marksman. If this model is killed, picked models that are deployed lose the rule.
➕ValiantIf most models in this unit have this rule, the first time they are attacked each round, they get +1 to Morale Test rolls.
➖CourageousUnits where all models have this rule get +1 to morale test rolls.
➖Piercing AssaultThis model gets AP(+1) when charging.
➖Piercing Assault AuraThis model and up to 3 nearest friendly units picked before the start of the game get Piercing Assault. If this model is killed, picked models that are deployed lose the rule.
➖Piercing HunterWhen this model shoots at enemies over 9" away, its weapons get AP(+1).

✏️Ambush
core rule		3.5.1: Only deploys D3 rounds afters its wave is deployed, and at the start of the round it's placed at the centre of a random table quarter.
3.6.0: Only deploys D3 rounds afters its wave, and at the start of the round it's placed within 6” of a random AI Goal.
✏️Battle-Hardened3.5.1: Units where all models have this rule get +1 to morale test rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, they get +1 to Morale Test rolls.
✏️Increased Shooting Range Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get +6" range when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get +6" range when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Surge
becomes a core rule		3.5.1: On unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
3.6.0: For each unmodified result of 6 to hit, this weapon deals 1 extra hit (only the original hit counts as a 6 for special rules).
