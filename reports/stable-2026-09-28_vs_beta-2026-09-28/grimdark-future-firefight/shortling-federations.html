Special rules

NameText
➕DestructiveWhen attacking units with more than half of their total size or Tough value (for single-model units), those hits get AP(+1).
➕Enhanced GuardedIf most models in this unit have Guarded, they always get +1 to Defense rolls from Guarded (instead of only as long as they haven't started an activation yet).
➕Enhanced Safety GearIf most models in this unit have Safety Gear, they always get +1 to Defense rolls from Safety Gear (instead of only as long as they haven't started an activation yet).
➕Enhanced Safety Gear AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Safety Gear. If this model is killed, picked models that are deployed lose the rule.
➖Safety Gear BoostIf all models in this unit have Safety Gear, they always get +1 to defense rolls from Safety Gear (instead of only when being shot/charged from over 9" away).
➖Safety Gear Boost AuraThis model and up to 3 friendly units picked before the start of the game get Safety Gear Boost. If this model is killed, picked models that are deployed lose the rule.
➖ShieldedUnits where all models have this rule get +1 to defense rolls against hits that are not from spells.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
✏️Fearless
core rule		3.5.1: When a unit where all models have this rule fails a morale test, roll one die. On a 4+ it counts as passed instead.
3.6.0: When a unit where most models have this rule fails a Morale Test, roll one die. On a 4+ it counts as passed instead.
✏️Guarded3.5.1: When units where all models have this rule are shot or charged from over 9" away, they get +1 to defense rolls.
3.6.0: If most models in this unit have this rule, as long as they haven't started an activation yet this round, they get +1 to Defense rolls.
✏️Morale Debuff3.5.1: Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which gets -1 to morale test rolls once (next time the effect would apply).
3.6.0: Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which gets -1 to Morale Test rolls once (next time the effect would apply).
✏️Precision Fighter Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get +1 to hit rolls in melee. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get +1 to hit rolls in melee. If this model is killed, picked models that are deployed lose the rule.
✏️Precision Frenzy3.5.1: Place one marker on this unit when it fully destroys an enemy unit, up to a max. of two markers. For each marker all models with this rule in this unit get +1 to hit rolls until the end of the game.
3.6.0: Place one token on this unit when it fully destroys an enemy unit, up to a max. of two tokens. For each token all models with this rule in this unit get +1 to hit rolls until the end of the game.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Rending
core rule		3.5.1: Ignores Regeneration, and on unmodified results of 6 to hit, those hits get AP(+4).
3.6.0: Ignores Regeneration, and for each unmodified result of 6 to hit, those hits get AP(+4).
✏️Rending when Shooting Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Rending when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Rending when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Safety Gear3.5.1: When units where all models have this rule are shot or charged from over 9" away, they get +1 to defense rolls.
