➕Grounded DefenseIf a unit where most models have this rule has most of them within 1" of terrain, they get +1 to Defense rolls.
➕Grounded Defense AuraThis model's unit and up to 2 friendly units picked before the start of the game get Grounded Defense. If this model is killed, picked models that are deployed lose the rule.
➕ReapWhen attacking units that are Shaken or Fatigued, the target must re-roll successful unmodified Defense results of 5-6.
➖DisintegrateIgnores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➖Grounded ReinforcementIf a unit where all models have this rule has most of them within 1" of terrain, they get +1 to defense rolls.
➖Grounded Reinforcement AuraThis model and up to 3 friendly units picked before the start of the game get Grounded Reinforcement. If this model is killed, picked models that are deployed lose the rule.
➖ReinforcementWhen a unit where all models have this rule is Shaken or fully destroyed, you may remove it from the table as destroyed and place a new copy of it fully within 12" of any table edge at the beginning of the next round after Ambushers have been deployed. Units that deploy via Reinforcement can’t seize or contest objectives on the round they deploy, and this rule doesn’t apply to the new copy of the unit.
✏️Bounding3.5.1: When this unit is activated, you may place all models with this rule in it anywhere fully within D3+1" of their position.
3.6.0: When this unit is activated, you may move all models with this rule in it by up to D3+1".
✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Models within 18” in line of sight of the caster’s unit may spend any number of spell tokens at the same time before rolling, to give the caster +1/-1 to the roll per token.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Models within 18” of the Caster may spend any number of spell tokens at the same time before rolling to give the Caster +1/-1 to the roll per token.
✏️Fanatic3.5.1: After this model is deployed, it may be placed anywhere fully within 9” of its position.
3.6.0: After this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.
✏️Grounded Precision3.5.1: If a unit where all models have this rule has most of them within 1" of terrain, they get +1 to hit rolls when attacking.
3.6.0: If most models in this unit are within 1" of terrain, this model gets +1 to hit rolls when attacking.
✏️Grounded Precision Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Grounded Precision. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Grounded Precision. If this model is killed, picked models that are deployed lose the rule.
✏️Melee Slayer3.5.1: When this model charges, its weapons get AP(+2) if most models in the target have Tough(3) or higher.
3.6.0: When charging, this model's weapons get AP(+2) if most models in the target have Tough(9) or higher.
✏️Melee Slayer Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Melee Slayer. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Melee Slayer. If this model is killed, picked models that are deployed lose the rule.
✏️Quick Shot Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Quick Shot. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Quick Shot. If this model is killed, picked models that are deployed lose the rule.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Slayer3.5.1: When this model shoots at enemies over 9" away, or when it charges, its weapons get AP(+2) if most models in the target have Tough(3) or higher.
3.6.0: When shooting enemies over 9" away, or when charging, this model's weapons get AP(+2) if most models in the target have Tough(9) or higher.
✏️Surge
becomes a core rule		3.5.1: On unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
3.6.0: For each unmodified result of 6 to hit, this weapon deals 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Takedown
core rule		3.5.1: This model may pick any model in the target unit as its individual target, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
3.6.0: This model may pick any model in the target unit as its individual target for this weapon's attacks, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
✏️Takedown Strike3.5.1: Once per game, when it's this model's turn to attack in melee, it may make one attack at Quality 2+ with AP(2), Deadly(3), and Takedown.
3.6.0: Once per game, when it's this model's turn to strike in melee, it may make X attacks at Quality 2+ with AP(2), Deadly(3), and Takedown.
✏️Vanguard3.5.1: After this model is deployed, it may be placed anywhere fully within 9” of its position.
3.6.0: After this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.

3.6.0: (3) Pick up to three friendly units within 18", which get Teleport once (next time the effect would apply).
✏️Brain Burst3.5.1: (3) Pick up to three enemy units within 6", which take 1 hit with AP(2) and Deadly(3) each.
3.6.0: (2) Pick one enemy unit within 6", which takes 2 hits with AP(2) and Deadly(3).
✏️Deep Hypnosis3.5.1: (2) Pick up to four enemy units within 18", which must take a morale test. If failed you may move it by up to 6" in a straight line in any direction.
3.6.0: (1) Pick one enemy unit within 18" in line of sight, which must take a Morale Test. If failed you may move it by up to 6" in a straight line in any direction. Units may only be moved once per round in this way.
✏️Insidious Protection3.5.1: (1) Pick up to two friendly units within 12", which get Grounded Reinforcement once (next time the effect would apply).
3.6.0: (2) Pick up to two friendly units within 12", which get Grounded Defense once (next time the effect would apply).
✏️Mind Corruption3.5.1: (1) Pick one enemy unit within 12", which takes 2 hits with AP(1) and Surge. Roll as many dice as hits to see if "on rolls of 6" effects trigger.
3.6.0: (3) Pick one enemy unit within 18" in line of sight, which takes 6 hits with Surge. Roll as many dice as hits to see if "on rolls of 6" effects trigger.
✏️Psychic Onslaught3.5.1: (2) Pick up to two enemy units within 12", which take 2 hits with Disintegrate each.
3.6.0: (1) Pick one enemy unit within 6", which takes 3 hits with AP(1) and Reap. Roll as many dice as hits to see if "on rolls of 6" effects trigger.
