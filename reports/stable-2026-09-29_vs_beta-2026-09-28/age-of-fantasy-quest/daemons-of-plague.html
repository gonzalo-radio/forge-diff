Special rules

NameText
➕DecimateWhen attacking units with more than half of their total size or Tough value (for single-model units), the target must re-roll unmodified Defense results of 6.
➕Enhanced PlagueboundIf most models in this unit have Plaguebound, they ignore wounds on rolls of 5-6 from Plaguebound (instead of only on 6+).
➕Enhanced ProtectedIf most models in this unit have Protected, they ignore wounds on rolls of 5-6 from Protected (instead of only on 6+).
➕RavageOnce per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
➕Ravage AuraThis model's unit and up to 2 friendly units picked before the start of the game get Ravage(+1). If this model is killed, picked models that are deployed lose the rule.
➖Plaguebound BoostIf all models in this unit have Plaguebound, they ignore wounds on rolls of 5-6 from Plaguebound (instead of only on 6+).
➖Rending in Melee AuraThis model and up to 3 friendly units picked before the start of the game get Rending in melee. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖Storm of PlagueOnly one use per game. Once per game, when this model is activated, before attacking, roll 3 dice. For each 2+ one enemy unit within 12" takes 3 hits with Bane.
➖SurgeOn unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
✏️Difficult Terrain Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which counts as being in Difficult Terrain once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which counts as being in Difficult terrain once (next time the effect would apply).
✏️Plaguebound3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Precision Attacks Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls when attacking once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls when attacking once (next time the effect would apply).
✏️Protected3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Rending
core rule		3.5.1: Ignores Regeneration, and on unmodified results of 6 to hit, those hits get AP(+4).
3.6.0: Ignores Regeneration, and for each unmodified result of 6 to hit, those hits get AP(+4).
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Steadfast3.5.1: If a unit where all models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
3.6.0: If a unit where most models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
