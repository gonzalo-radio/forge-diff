Special rules

NameText
➕Enhanced Hold the LineIf most models in this unit have Hold the Line, they always get +1 to Morale Test rolls from Hold the Line (instead of only the first time they are attacked each round).
➕Enhanced ValiantIf most models in this unit have Valiant, they always get +1 to Morale Test rolls from Valiant (instead of only the first time they are attacked each round).
➕FractureFor each unmodified result of 6 to hit, those hits get AP(+2).
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➕ValiantIf most models in this unit have this rule, the first time they are attacked each round, they get +1 to Morale Test rolls.
➖Breath AttackOnly one use per game. Once per activation, before attacking, roll one die. On a 2+ one enemy unit within 6" in line of sight takes 1 hit with Blast(3) and AP(1).
➖CourageousUnits where all models have this rule get +1 to morale test rolls.
➖CrackOn unmodified results of 6 to hit, those hits get AP(+2).
➖Hold the Line BoostIf all models in this unit have Hold the Line, they get +2 to morale test rolls from Hold the Line (instead of only +1).
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
✏️Bounding3.5.1: When this unit is activated, you may place all models with this rule in it anywhere fully within D3+1" of their position.
3.6.0: When this unit is activated, you may move all models with this rule in it by up to D3+1".
✏️Defense Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to defense rolls once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to Defense rolls once (next time the effect would apply).
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Hero
core rule		3.5.1: Friendly units within 12” may take morale tests using the hero’s Quality, as long as the hero isn’t Shaken.
3.6.0: Units within 6” of friendly Heroes may use the Hero’s Quality for Morale Tests as long as the Hero isn’t Shaken.
✏️Hold the Line3.5.1: Units where all models have this rule get +1 to morale test rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, they get +1 to Morale Test rolls.
✏️Martial Prowess3.5.1: Once per game, if all models in this unit have this rule, it may be activated even if it had already activated this round (stops being fatigued when activated for the second time). Only up to one third of the units in the army with this rule at the beginning of the game (rounding up) may use it in a single round.
3.6.0: Once per game, if all models in this unit have this rule, it may be activated even if it had already activated this round (stops being Fatigued when activated again). Only up to one third of the units in the army with this rule at the beginning of the game (rounding up) may use it in a single round.
✏️Precision Fighter Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
✏️Precision Fighting Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
✏️Precision Shooter Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls when shooting once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls when shooting once (next time the effect would apply).
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
