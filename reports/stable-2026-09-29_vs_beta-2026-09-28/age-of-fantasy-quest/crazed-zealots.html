Special rules

NameText
➕Enhanced CrazedIf this model has Crazed, it gets extra attacks on successful unmodified hit results of 5-6 from Crazed (instead of only on 6).
➕Enhanced PredatorIf this model has Predator, it gets extra attacks on successful unmodified hit results of 5-6 from Predator (instead of only on 6).
➕PunctureIgnores Regeneration, and when attacking units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➕RavageOnce per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
➖Crazed BoostIf this model has Crazed, it gets extra attacks on successful unmodified hit results of 5-6 from Crazed (instead of only on 6).
➖DisintegrateIgnores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
✏️Hit & Run3.5.1: Once per round, units where all models have this rule may move by up to 3" after shooting or being in melee.
3.6.0: Once per round, this model may move by up to 3" after shooting or being in melee.
✏️Hit & Run Fighter3.5.1: Once per round, units where all models have this rule may move by up to 3" after being in melee.
3.6.0: Once per round, this model may move by up to 3" after being in melee.
✏️Hit & Run Fighter Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Hit & Run Fighter. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Hit & Run Fighter. If this model is killed, picked models that are deployed lose the rule.
✏️Protection Feat3.5.1: Once per game, when this unit takes wounds and all its models have this rule, you may use this rule and roll one die per wound, and on a 5+ it is ignored.
3.6.0: Once per game, when this unit takes wounds and most of its models have this rule, you may use this rule and roll one die per wound, and on a 5+ it is ignored.
✏️Protection Feat Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Protection Feat. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Protection Feat. If this model is killed, picked models that are deployed lose the rule.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Shielded3.5.1: Units where all models have this rule get +1 to defense rolls against hits that are not from spells.
3.6.0: Units where most models have this rule get +1 to Defense rolls against hits that are not from spells.
✏️Unpredictable Fighter Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Unpredictable Fighter against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Unpredictable Fighter against once (next time the effect would apply).
