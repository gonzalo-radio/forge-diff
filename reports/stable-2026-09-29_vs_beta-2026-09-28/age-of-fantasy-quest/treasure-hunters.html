Special rules

NameText
➕AgileMoves +1" when using Advance, and +2" when using Rush/Charge.
➕BraveryUnits where most models have this rule get +1 to Morale Test rolls.
➕Enhanced AgileIf this model has Agile, it moves +2" on Advance and +4" on Rush/Charge from Agile (instead of only +1" and +2").
➕Enhanced RunnerIf this model has Runner, it moves +2" on Advance and +4" on Rush/Charge from Runner (instead of only +1" and +2").
➕FractureFor each unmodified result of 6 to hit, those hits get AP(+2).
➕Precision SpotterOnly one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. Friendly units may remove tokens from their target before rolling to hit to get +X to hit rolls when attacking, where X is the number of removed tokens.
➖Courage AuraThis model and up to 3 friendly units picked before the start of the game get +1 to morale test rolls. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖CrackOn unmodified results of 6 to hit, those hits get AP(+2).
➖Piercing SpotterOnly one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a marker on it. When attacking, friendly units may remove markers from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed markers.
➖QuickMoves +2" when using Advance, and +2” when using Rush/Charge.
➖Runner BoostIf this model has Runner, it moves +4" on Advance and +4" on Rush/Charge from Runner (instead of only +2" and +2").
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
✏️Melee Shrouding3.5.1: Enemies get -3" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -2" range to a min. of 6" when charging it.
✏️Precision Fighting Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units get +1 to hit rolls in melee against once (next time the effect would apply).
✏️Runner3.5.1: Moves +2" when using Advance, and +2” when using Rush/Charge.
3.6.0: Moves +1" when using Advance, and +2" when using Rush/Charge.
✏️Stealth
core rule		3.5.1: When units where all models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
3.6.0: When units where most models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
