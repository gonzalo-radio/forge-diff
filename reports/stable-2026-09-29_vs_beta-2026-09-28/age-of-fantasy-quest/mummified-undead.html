➖Breath AttackOnly one use per game. Once per activation, before attacking, roll one die. On a 2+ one enemy unit within 6" in line of sight takes 1 hit with Blast(3) and AP(1).
➖DestructiveOn unmodified results of 6 to hit, those hits get AP(+4).
➖Reach HuntThis model gets +4" range when shooting and moves +2" when using Charge actions.
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.

✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Difficult Terrain Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which counts as being in Difficult Terrain once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which counts as being in Difficult terrain once (next time the effect would apply).
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Fortified Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Fortified. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Fortified. If this model is killed, picked models that are deployed lose the rule.
✏️Piercing Spotter3.5.1: Only one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a marker on it. When attacking, friendly units may remove markers from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed markers.
3.6.0: Only one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. When attacking, friendly units may remove tokens from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed tokens.
✏️Royal Legion3.5.1: This model gets +4" range when shooting and moves +2" when using Charge actions.
3.6.0: This model gets +6" range when using Hold actions and shooting, and moves +2" when using Charge actions.
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Shred
becomes a core rule		3.5.1: On unmodified results of 1 to block hits, this weapon deals 1 extra wound.
3.6.0: For each unmodified result of 1 to block hits, this weapon deals 1 extra wound.
✏️Vanguard3.5.1: After this model is deployed, it may be placed anywhere fully within 9” of its position.
3.6.0: After this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.
