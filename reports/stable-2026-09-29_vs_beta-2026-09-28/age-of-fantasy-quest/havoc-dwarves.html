Special rules

NameText
➕Enhanced HavocboundIf this model has Havocbound, it always gets AP(+1) from Havocbound (instead of only when attacking enemies that already finished an activation).
➕Enhanced Piercing WarriorIf this model has Piercing Warrior, it always gets AP(+1) from Piercing Warrior (instead of only when attacking enemies that already finished an activation).
➕Piercing MarksmanWhen shooting at enemies over 9" away, this model's weapons get AP(+1).
➕PurgeWhen attacking units that are Shaken or Fatigued, this weapon gets AP(+2).
➕Steadfast AuraThis model's unit and up to 2 friendly units picked before the start of the game get Steadfast. If this model is killed, picked models that are deployed lose the rule.
➖DisintegrateIgnores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➖Havocbound BoostIf this model has Havocbound, it always gets AP(+1) from Havocbound (instead of only when shooting over 9" away, or when charging).
➖Piercing HunterWhen this model shoots at enemies over 9" away, its weapons get AP(+1).
➖Steadfast BuffOnly one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets Steadfast once (next time the effect would apply).
✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Heroes may spend any number of spell tokens before rolling to get +1 to the roll per token, or to give an enemy caster within 18” and in line of sight -1 to their roll per token. Whenever a hero fails to cast a spell, it may spend X*2 power to count as having cast it instead, where X is the spell’s casting value.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Heroes may spend any number of tokens/power before rolling to get +1 to the roll per token/power, or to give an enemy Caster within 18” -1 to their roll per token/power.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Havocbound3.5.1: When this model shoots at enemies over 9" away, or when it charges, its weapons get AP(+1).
3.6.0: When this model attacks enemies for the first time each round, its weapons get AP(+1).
✏️Melee Shrouding3.5.1: Enemies get -3" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -2" range to a min. of 6" when charging it.
✏️Piercing Warrior3.5.1: When this model shoots at enemies over 9" away, or when it charges, its weapons get AP(+1).
3.6.0: When this model attacks enemies for the first time each round, its weapons get AP(+1).
✏️Relentless
core rule		3.5.1: When this model shoots at enemies over 9" away, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model shoots at enemies over 9” away, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Relentless Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Relentless against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Relentless against once (next time the effect would apply).
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Steadfast3.5.1: If a unit where all models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
3.6.0: If a unit where most models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
✏️Versatile Defense3.5.1: When a unit where all models have this rule is deployed or activated, pick one effect: when shot or charged from over 9" away, the unit either gets +1 to defense rolls, or enemy units get -1 to hit rolls against it. This effect lasts until the units' next activation.
3.6.0: As long as a unit where most models have this rule hasn't activated yet this round, pick one effect when it is attacked: the unit either gets +1 to Defense rolls, or enemy units get -1 to hit rolls against it. Note that you may pick a different effect each time the unit is attacked.
✏️Versatile Defense Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule.
