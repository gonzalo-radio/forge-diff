Special rules

NameText
➕DestructiveWhen attacking units with more than half of their total size or Tough value (for single-model units), those hits get AP(+1).
➕DodgeIf most models in this unit have this rule, as long as they aren't Fatigued, enemy units get -1 to hit rolls in melee against them.
➕Enhanced ShadowbornIf most models in this unit have Shadowborn, attackers always get -4"/-2" range when targeting it from Shadowborn (instead of only the first time they are attacked each round).
➕Enhanced Shadowborn AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Shadowborn. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced ShroudedIf most models in this unit have Shrouded, attackers always get -4"/-2" range when targeting it from Shrouded (instead of only the first time they are attacked each round).
➕ImpreciseGets -1 to hit when attacking.
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➕Unique HeroThis hero may only be taken once per party.
➖Breath AttackOnly one use per game. Once per activation, before attacking, roll one die. On a 2+ one enemy unit within 6" in line of sight takes 1 hit with Blast(3) and AP(1).
➖Counter-AttackStrikes first when charged.
➖DisintegrateIgnores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
➖EvasiveEnemies get -1 to hit rolls when attacking units where all models have this rule.
➖Good FighterThis model gets +1 to hit rolls in melee.
➖Melee EvasionEnemies get -1 to hit rolls in melee when attacking units where all models have this rule.
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➖Shadowborn BoostIf all models in this unit have Shadowborn, enemies get -8" range to a min. of 6" when shooting them, and -4" movement to a min. of 6" when charging them from Shadowborn (instead of only -4" and -2").
➖Shadowborn Boost AuraThis model and up to 3 friendly units picked before the start of the game get Shadowborn Boost. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
✏️Ethereal3.5.1: Once per activation, before attacking, place this model anywhere fully within 6" of its position. This model moves -6" when using Advance, and -6” when using Rush/Charge.
3.6.0: Once per activation, before attacking, you may place this model anywhere fully within 6" of its position. If you do, this model moves -6" when using Advance, and -6" when using Rush/Charge until the end of that activation.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Precision Target3.5.1: Only one use per game. Once per game, during this model's activation, pick one enemy unit within 18" and in line of sight of it, and place X markers on it. Friendly units get +X to hit rolls when attacking it.
3.6.0: Only one use per game. Once per game, during this model's activation, pick X enemy units within 18" and in line of sight of it, and place one token on them. Friendly units get +1 to hit rolls when attacking them.
✏️Ravage3.5.1: When it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
3.6.0: Once per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Shadowborn3.5.1: Enemies get -4" range to a min. of 6" when trying to shoot at units where all models have this rule, and -2" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -4"/-2" range to a min. of 6" when shooting/charging it.
✏️Shrouded3.5.1: Enemies get -4" range to a min. of 6" when trying to shoot at units where all models have this rule, and -2" movement to a min. of 6" when trying to charge units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -4"/-2" range to a min. of 6" when shooting/charging it.
✏️Unpredictable Fighter Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Unpredictable Fighter against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Unpredictable Fighter against once (next time the effect would apply).
