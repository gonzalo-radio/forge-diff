✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Heroes may spend any number of spell tokens before rolling to get +1 to the roll per token, or to give an enemy caster within 18” and in line of sight -1 to their roll per token. Whenever a hero fails to cast a spell, it may spend X*2 power to count as having cast it instead, where X is the spell’s casting value.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Heroes may spend any number of tokens/power before rolling to get +1 to the roll per token/power, or to give an enemy Caster within 18” -1 to their roll per token/power.
✏️Counter
core rule		3.5.1: Strikes first with this weapon when charged, and the charging unit gets -1 total Impact rolls per model with Counter.
3.6.0: May strike first with this weapon when charged, unless this unit is Fatigued.
✏️Defense Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which gets -1 to defense rolls once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which gets -1 to Defense rolls once (next time the effect would apply).
✏️Evasive3.5.1: Enemies get -1 to hit rolls when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls when attacking units where most models have this rule.
✏️Evasive Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Evasive. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Evasive. If this model is killed, picked models that are deployed lose the rule.
✏️Hazardous3.5.1: Gets AP(4), but this model's unit takes one wound on unmodified rolls of 1 to hit.
3.6.0: Gets AP(4), but on unmodified results of 1 to hit this model takes one wound, or X wounds if this weapon has the Blast(X)/Deadly(X) rule.
✏️Impact
core rule		3.5.1: Roll X dice when attacking after charging, unless fatigued. For each 2+ the target takes one hit.
3.6.0: When charging, before either unit attacks, roll X dice, unless this unit is Fatigued. For each 2+ the target takes 1 hit.
✏️Precision Fighter Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to hit rolls in melee once (next time the effect would apply).
✏️Reinforcement3.5.1: When a unit where all models have this rule is Shaken or fully destroyed, you may remove it from the table as destroyed and place a new copy of it fully within 12" of any table edge at the beginning of the next round after Ambushers have been deployed. Units that deploy via Reinforcement can’t seize or contest objectives on the round they deploy, and this rule doesn’t apply to the new copy of the unit.
3.6.0: When a unit where all models have this rule is Shaken, you may remove it from the table as destroyed. At the beginning of the next round after a unit where all models have this rule is destroyed, after Ambushers have been deployed, you may place a new copy of it fully within 9" of any table edge, over 9" away from enemy units. Units that deploy via Reinforcement can’t seize or contest objectives on the round they deploy, and this rule doesn’t apply to the new copy of the unit.
✏️Scurry3.5.1: Moves +2" when using Advance, and +2” when using Rush/Charge.
3.6.0: Moves +1" when using Advance, and +2" when using Rush/Charge.
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Takedown
core rule		3.5.1: This model may pick any model in the target unit as its individual target, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
3.6.0: This model may pick any model in the target unit as its individual target for this weapon's attacks, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
✏️Takedown Strike3.5.1: Once per game, when it's this model's turn to attack in melee, it may make one attack at Quality 2+ with AP(2), Deadly(3), and Takedown.
3.6.0: Once per game, when it's this model's turn to strike in melee, it may make X attacks at Quality 2+ with AP(2), Deadly(3), and Takedown.
✏️Vanguard3.5.1: After this model is deployed, it may be placed anywhere fully within 9” of its position.
3.6.0: After this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.
