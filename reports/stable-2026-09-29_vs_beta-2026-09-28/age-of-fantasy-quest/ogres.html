Special rules

NameText
➕BraveryUnits where most models have this rule get +1 to Morale Test rolls.
➕Enhanced DestroyerIf this model has Destroyer, enemies always take wounds on unmodified results of 1 to block from Destroyer (instead of only when attacking enemies that already finished an activation).
➕Enhanced ViolentIf this model has Violent, enemies always take wounds on unmodified results of 1 to block from Violent (instead of only when attacking enemies that already finished an activation).
➕FragmentWhen attacking units where most models have Defense 4+ to Defense 6+, the target must re-roll successful unmodified Defense results of 4-6.
➕Heavy ImpactCounts as having Impact(X) with hits that have AP(1).
➕Melee Evasion BuffOnly one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets Melee Evasion once (next time the effect would apply).
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➖Counter-AttackStrikes first when charged.
➖Courage AuraThis model and up to 3 friendly units picked before the start of the game get +1 to morale test rolls. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖Destroyer BoostIf this model has Destroyer, when it shoots or charges enemies over 9" away, enemies taking wounds from it take extra wounds on failed defense rolls of 1-2 from Destroyer (instead of only on 1).
➖DestructiveOn unmodified results of 6 to hit, those hits get AP(+4).
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
✏️Destroyer3.5.1: Enemies that roll to block hits from this model's weapons take 1 extra wound for each unmodified result of 1 that they roll.
3.6.0: When this model attacks enemies for the first time each round, unmodified results of 1 to block hits from weapons deal 1 extra wound.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).

3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets +1 to Morale Test rolls triggered by shooting/melee once (next time the effect would apply).
✏️Great Musician3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which moves +1" when using move actions once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which moves +1" when using move actions once (next time the effect would apply).
✏️Great Sergeant3.5.1: When this model attacks, unmodified results of 5-6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+2) when attacking.
✏️Melee Evasion3.5.1: Enemies get -1 to hit rolls in melee when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls in melee when attacking units where most models have this rule.
✏️Piercing Feat3.5.1: Once per game, when this unit attacks and all its models have this rule, you may use this rule so that all their weapons get AP(+1).
3.6.0: Once per game, when this unit attacks, you may use this rule so that the weapons of all models with this rule in it get AP(+1).
✏️Ravage3.5.1: When it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
3.6.0: Once per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.

core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).

core rule		3.5.1: This model may pick any model in the target unit as its individual target, which is resolved as if it was a unit of [1]. Takedown attacks must be resolved before other weapons.
