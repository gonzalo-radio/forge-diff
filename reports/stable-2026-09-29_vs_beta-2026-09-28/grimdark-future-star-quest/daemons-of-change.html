Special rules

NameText
➕Enhanced ChangeboundIf most models in this unit have Changebound, enemies attacking them always get -1 to hit rolls from Changebound (instead of only the first time they are attacked each round).
➕Enhanced ScreenedIf most models in this unit have Screened, enemies attacking them always get -1 to hit rolls from Screened (instead of only the first time they are attacked each round).
➕Heavy ImpactCounts as having Impact(X) with hits that have AP(1).
➕LacerateWhen attacking, the target must re-roll unmodified Defense results of 6.
➕Spell DrainOnce per activation, before attacking, pick one enemy model within 18" in line of sight, which must take a Morale Test. If failed, it loses 2 spell tokens.
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➕Unique HeroThis hero may only be taken once per party.
➖Casting DebuffOnly one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight with Caster, which gets -1 to casting rolls once (next time the effect would apply).
➖Changebound BoostIf all models in this unit have Changebound, enemies attacking them always get -1 to hit rolls from Changebound (instead of only when being shot/charged from over 9" away).
➖Protected AuraThis model and up to 3 friendly units picked before the start of the game get Protected. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖SplitWhen this unit is fully destroyed, you may place a new unit of X fully within 6" of it before removing the last model.
➖Storm of ChangeOnly one use per game. Once per game, when this model is activated, before attacking, roll 3 dice. For each 2+ one enemy unit within 12" takes 3 hits with Shred.
➖SurgeOn unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
➖Teleport AuraThis model and up to 3 friendly units picked before the start of the game get Teleport. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
✏️Bounding3.5.1: When this unit is activated, you may place all models with this rule in it anywhere fully within D3+1" of their position.
3.6.0: When this unit is activated, you may move all models with this rule in it by up to D3+1".
✏️Bounding Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Bounding. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Bounding. If this model is killed, picked models that are deployed lose the rule.
✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Heroes may spend any number of spell tokens before rolling to get +1 to the roll per token, or to give an enemy caster within 18” and in line of sight -1 to their roll per token. Whenever a hero fails to cast a spell, it may spend X*2 power to count as having cast it instead, where X is the spell’s casting value.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Heroes may spend any number of tokens/power before rolling to get +1 to the roll per token/power, or to give an enemy Caster within 18” -1 to their roll per token/power.
✏️Changebound3.5.1: When units where all models have this rule are shot or charged from over 9" away, enemy units get -1 to hit rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, enemy units attacking them get -1 to hit rolls.
✏️Protected3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Screened3.5.1: When units where all models have this rule are shot or charged from over 9" away, enemy units get -1 to hit rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, enemy units attacking them get -1 to hit rolls.
✏️Sergeant
core rule		3.5.1: When this model attacks, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: This model gets AP(+1) when attacking.
✏️Unstoppable
core rule		3.5.1: Ignores Regeneration, and ignores all negative modifiers to this weapon.
3.6.0: Ignores Regeneration, and ignores all negative modifiers to this weapon which are not from this model's special rules.
