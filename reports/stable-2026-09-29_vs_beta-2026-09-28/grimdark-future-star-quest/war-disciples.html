Special rules

NameText
➕Bravery AuraThis model's unit and up to 2 friendly units picked before the start of the game get +1 to Morale Test rolls. If this model is killed, picked models that are deployed lose the rule.
➕Crossing StrikeOnce per activation, when this model moves through enemy units, pick one of them and attack it with this weapon as if it was shooting. This weapon may only be used in this way.
➕Enhanced ViolentIf this model has Violent, enemies always take wounds on unmodified results of 1 to block from Violent (instead of only when attacking enemies that already finished an activation).
➕Enhanced WarboundIf this model has Warbound, enemies always take wounds on unmodified results of 1 to block from Warbound (instead of only when attacking enemies that already finished an activation).
➕Heavy ImpactCounts as having Impact(X) with hits that have AP(1).
➕PurgeWhen attacking units that are Shaken or Fatigued, this weapon gets AP(+2).
➕ScourgeFor each unmodified result of 1 to block hits, this weapon counts as having dealt 2 extra wounds when checking who won melee, or if shooting wounds would trigger Morale Tests.
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➕Versatile ExpertWhen this unit is activated, pick one effect: until the end of the activation all models with this rule in this unit either get AP(+1) when attacking, or get +1 to hit rolls when attacking.
➖CrackOn unmodified results of 6 to hit, those hits get AP(+2).
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖Versatile AttackWhen this unit is activated, pick one effect: until the end of the activation, when shooting or charging enemies over 9" away, all models with this rule in this unit either get AP(+1) or get +1 to hit rolls.
➖Warbound BoostIf this model has Warbound, when it shoots or charges enemies over 9" away, enemies taking wounds from it take extra wounds on failed defense rolls of 1-2 from Warbound (instead of only on 1).
✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Dangerous Terrain Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which counts as being in Dangerous Terrain once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which counts as being in Dangerous terrain once (next time the effect would apply).
✏️Melee Evasion3.5.1: Enemies get -1 to hit rolls in melee when attacking units where all models have this rule.
3.6.0: Enemies get -1 to hit rolls in melee when attacking units where most models have this rule.
✏️Steadfast3.5.1: If a unit where all models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
3.6.0: If a unit where most models have this rule is Shaken at the beginning of the round, roll one die. On a 4+, it stops being Shaken.
✏️Steadfast Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Steadfast. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Steadfast. If this model is killed, picked models that are deployed lose the rule.
✏️Versatile Defense3.5.1: When a unit where all models have this rule is deployed or activated, pick one effect: when shot or charged from over 9" away, the unit either gets +1 to defense rolls, or enemy units get -1 to hit rolls against it. This effect lasts until the units' next activation.
3.6.0: As long as a unit where most models have this rule hasn't activated yet this round, pick one effect when it is attacked: the unit either gets +1 to Defense rolls, or enemy units get -1 to hit rolls against it. Note that you may pick a different effect each time the unit is attacked.
✏️Versatile Defense Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Versatile Defense. If this model is killed, picked models that are deployed lose the rule.
✏️Violent3.5.1: Enemies that roll to block hits from this model's weapons take 1 extra wound for each unmodified result of 1 that they roll.
3.6.0: When this model attacks enemies for the first time each round, unmodified results of 1 to block hits from weapons deal 1 extra wound.
✏️Warbound3.5.1: Enemies that roll to block hits from this model's weapons take 1 extra wound for each unmodified result of 1 that they roll.
3.6.0: When this model attacks enemies for the first time each round, unmodified results of 1 to block hits from weapons deal 1 extra wound.
