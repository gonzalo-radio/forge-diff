Special rules

NameText
➕Crossing StrikeOnce per activation, when this model moves through enemy units, pick one of them and attack it with this weapon as if it was shooting. This weapon may only be used in this way.
➕Enhanced BrutalIf this model has Brutal, the target always takes hits on unmodified hit results of 6 from Brutal (instead of only when attacking enemies that already finished an activation).
➕Enhanced FerociousIf this model has Ferocious, the target always takes hits on unmodified hit results of 6 from Ferocious (instead of only when attacking enemies that already finished an activation).
➕Heavy ImpactCounts as having Impact(X) with hits that have AP(1).
➕PierceIgnores Cover, and when attacking units over half of this weapon's range away, this weapon gets AP(+1).
➕Precision ChargeThis model gets +1 to hit rolls when charging.
➕Spell ResistanceWhen a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➕Unique HeroThis hero may only be taken once per party.
➖Ferocious BoostIf this model has Ferocious, when it shoots or charges enemies over 9" away, it deals extra hits on successful unmodified hit results of 5-6 from Ferocious (instead of only on 6).
➖Piercing AssaultThis model gets AP(+1) when charging.
➖Precision Charge AuraThis model and up to 3 friendly units picked before the start of the game get +1 to hit rolls when charging. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
➖RavageWhen it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
➖ResistanceWhen a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored. If the wounds were from a spell, then they are ignored on a 2+ instead.
➖ShieldedUnits where all models have this rule get +1 to defense rolls against hits that are not from spells.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖StrafingOnce per activation, when this model moves through enemy units, pick one of them and attack it with this weapon as if it was shooting. This weapon may only be used in this way.
➖SurgeOn unmodified results of 6 to hit, this weapon deals 1 extra hits (only the original hit counts as a 6 for special rules).
➖TearAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+4).
✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Bounding3.5.1: When this unit is activated, you may place all models with this rule in it anywhere fully within D3+1" of their position.
3.6.0: When this unit is activated, you may move all models with this rule in it by up to D3+1".
✏️Brutal3.5.1: When attacking, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model attacks enemies for the first time each round, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Ferocious3.5.1: When attacking, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model attacks enemies for the first time each round, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Hit & Run Fighter3.5.1: Once per round, units where all models have this rule may move by up to 3" after being in melee.
3.6.0: Once per round, this model may move by up to 3" after being in melee.
✏️Protected3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Ranged Shrouding3.5.1: Enemies get -6" range to a min. of 6" when trying to shoot units where all models have this rule.
3.6.0: When a unit where most models have this rule is targeted by an enemy, as long as this unit hasn't started an activation yet this round, attackers get -4"" range to a min. of 6" when shooting at it.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Rending
core rule		3.5.1: Ignores Regeneration, and on unmodified results of 6 to hit, those hits get AP(+4).
3.6.0: Ignores Regeneration, and for each unmodified result of 6 to hit, those hits get AP(+4).
✏️Rending Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Rending against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Rending against once (next time the effect would apply).
✏️Speed Feat3.5.1: Once per game, when this unit moves and all its models have this rule, you may use this rule so that they move +2" when using Advance actions and +4" when using Rush/Charge actions.
3.6.0: Once per game, when this unit moves, you may use this rule so that all models with this rule in it move +2" when using Advance actions and +4" when using Rush/Charge actions.
✏️Speed Feat Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Speed Feat. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Speed Feat. If this model is killed, picked models that are deployed lose the rule.
