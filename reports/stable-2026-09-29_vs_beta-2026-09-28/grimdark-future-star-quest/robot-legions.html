✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Heroes may spend any number of spell tokens before rolling to get +1 to the roll per token, or to give an enemy caster within 18” and in line of sight -1 to their roll per token. Whenever a hero fails to cast a spell, it may spend X*2 power to count as having cast it instead, where X is the spell’s casting value.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Heroes may spend any number of tokens/power before rolling to get +1 to the roll per token/power, or to give an enemy Caster within 18” -1 to their roll per token/power.
✏️Indirect Mark3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Indirect against once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Indirect against once (next time the effect would apply).
✏️Protected3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Protection Feat3.5.1: Once per game, when this unit takes wounds and all its models have this rule, you may use this rule and roll one die per wound, and on a 5+ it is ignored.
3.6.0: Once per game, when this unit takes wounds and most of its models have this rule, you may use this rule and roll one die per wound, and on a 5+ it is ignored.
✏️Ravage3.5.1: When it's this model's turn to attack in melee, roll X dice. For each 6+ the target takes one wound.
3.6.0: Once per round, when it’s this model’s turn to strike in melee, roll X dice before attacking, unless this unit is Fatigued. For each 6+ the target takes one wound.
✏️Rending
core rule		3.5.1: Ignores Regeneration, and on unmodified results of 6 to hit, those hits get AP(+4).
3.6.0: Ignores Regeneration, and for each unmodified result of 6 to hit, those hits get AP(+4).
✏️Self-Repair3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 6+ it is ignored.
✏️Swift Buff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 friendly units within 12", which gets Swift once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 friendly units within 12", which gets Swift once (next time the effect would apply).
✏️Unstoppable
core rule		3.5.1: Ignores Regeneration, and ignores all negative modifiers to this weapon.
3.6.0: Ignores Regeneration, and ignores all negative modifiers to this weapon which are not from this model's special rules.
