✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Heroes may spend any number of spell tokens before rolling to get +1 to the roll per token, or to give an enemy caster within 18” and in line of sight -1 to their roll per token. Whenever a hero fails to cast a spell, it may spend X*2 power to count as having cast it instead, where X is the spell’s casting value.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Heroes may spend any number of tokens/power before rolling to get +1 to the roll per token/power, or to give an enemy Caster within 18” -1 to their roll per token/power.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Highborn3.5.1: Moves +2" when using Advance, and +2” when using Rush/Charge.
3.6.0: This model gets +6" range when using Hold actions and shooting, and moves +2" when using Charge actions.
✏️Hit & Run Shooter3.5.1: Once per round, units where all models have this rule may move by up to 3" after shooting.
3.6.0: Once per round, this model may move by up to 3" after shooting.
✏️Piercing Spotter3.5.1: Only one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a marker on it. When attacking, friendly units may remove markers from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed markers.
3.6.0: Only one use per game. Once per activation, pick one enemy unit within 30" and in line of sight of this model and roll one die, on a 4+ place a token on it. When attacking, friendly units may remove tokens from their target before rolling to block to get +AP(X) on their weapons, where X is the number of removed tokens.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Regeneration Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Regeneration. If this model is killed, picked models that are deployed lose the rule.
✏️Scout Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Scout. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Scout. If this model is killed, picked models that are deployed lose the rule.
✏️Shred
becomes a core rule		3.5.1: On unmodified results of 1 to block hits, this weapon deals 1 extra wound.
3.6.0: For each unmodified result of 1 to block hits, this weapon deals 1 extra wound.
✏️Stealth
core rule		3.5.1: When units where all models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
3.6.0: When units where most models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
✏️Stealth Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule. This effect lasts until the first wave of reinforcements is deployed.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule.
✏️Unwieldy Debuff3.5.1: Only one use per game. Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which gets Unwieldy in melee once (next time the effect would apply).
3.6.0: Only one use per game. Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which gets Unwieldy in melee once (next time the effect would apply).
