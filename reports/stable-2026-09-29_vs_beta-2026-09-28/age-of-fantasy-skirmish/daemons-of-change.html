✏️Caster
core rule		3.5.1: Gets X spell tokens at the start of each round, but can’t hold more than 6 tokens at once. At any point before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Roll one die, on 4+ resolve the effect on a target in line of sight. Models within 18” in line of sight of the caster’s unit may spend any number of spell tokens at the same time before rolling, to give the caster +1/-1 to the roll per token.
3.6.0: Gets X spell tokens at the start of each round, but can’t have more than 6 at once. Once per activation, before attacking, spend as many tokens as the spell’s value to try casting one or more spells (only one try per spell). Pick a target and roll one die, and on 4+ resolve the spell’s effect. Models within 18” of the Caster may spend any number of spell tokens at the same time before rolling to give the Caster +1/-1 to the roll per token.
✏️Changebound3.5.1: When units where all models have this rule are shot or charged from over 9" away, enemy units get -1 to hit rolls.
3.6.0: If most models in this unit have this rule, as long as they haven't started an activation yet this round, enemy units attacking them get -1 to hit rolls.
✏️Fear
core rule		3.5.1: This model counts as having dealt +X wounds when checking wound effects in melee (must deal at least one wound).
3.6.0: This model counts as having dealt +X wounds when checking who won melee.
✏️Fearless
core rule		3.5.1: When a unit where all models have this rule fails a morale test, roll one die. On a 4+ it counts as passed instead.
3.6.0: When a unit where most models have this rule fails a Morale Test, roll one die. On a 4+ it counts as passed instead.
✏️Fearless Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Fearless. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Fearless. If this model is killed, picked models that are deployed lose the rule.
✏️Indirect
core rule		3.5.1: Gets -1 to hit rolls when shooting after moving. May target enemies that are not in line of sight as if in line of sight, and ignores cover from sight obstructions.
3.6.0: When using Hold actions and shooting, may target enemies that are not in line of sight as if in line of sight, and ignores Cover from Sight Blockers.
✏️Indirect when Shooting Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Indirect when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Indirect when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Screened3.5.1: When units where all models have this rule are shot or charged from over 9" away, enemy units get -1 to hit rolls.
