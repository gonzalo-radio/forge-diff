NameText
➕DisintegrateIgnores Regeneration, and when attacking units where most models have Tough(9) or higher, this weapon gets AP(+2).
➕Enhanced BestialIf this model has Bestial, enemies taking hits from it must re-roll successful unmodified Defense results of 5-6 from Bestial (instead of only results of 6).
➕Enhanced Bestial AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Bestial. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced ViciousIf this model has Vicious, enemies taking hits from it must re-roll successful unmodified Defense results of 5-6 from Vicious (instead of only results of 6).
➕Piercing ChargeThis model gets AP(+1) when charging.
➕Piercing Charge AuraThis model's unit and up to 2 friendly units picked before the start of the game get Piercing Charge. If this model is killed, picked models that are deployed lose the rule.
➕Unique HeroCounts as having Hero, and this model may only be taken once per army.
➖Bestial BoostIf this model has Bestial, when it shoots or charges enemies over 9" away, enemies taking hits from it must re-roll successful unmodified defense results of 5-6 from Bestial (instead of only on 6).
➖Bestial Boost AuraThis model and up to 3 friendly units picked before the start of the game get Bestial Boost. If this model is killed, picked models that are deployed lose the rule.
➖Piercing AssaultThis model gets AP(+1) when charging.
➖Piercing Assault AuraThis model and up to 3 friendly units picked before the start of the game get Piercing Assault. If this model is killed, picked models that are deployed lose the rule.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖TearAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+4).
✏️Ambush Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Ambush. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Ambush. If this model is killed, picked models that are deployed lose the rule.
✏️Furious
core rule		3.5.1: When charging, unmodified results of 6 to hit in melee deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When charging, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Furious Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
