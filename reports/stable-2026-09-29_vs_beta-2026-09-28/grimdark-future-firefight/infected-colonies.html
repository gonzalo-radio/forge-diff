Special rules

NameText
➕DecimateWhen attacking units with more than half of their total size or Tough value (for single-model units), the target must re-roll unmodified Defense results of 6.
➕Enhanced InfectedIf this model has Infected, enemies always take wounds on unmodified results of 1 to block from Infected (instead of only when attacking enemies that already finished an activation).
➕Enhanced Infected AuraThis model's unit and up to 2 friendly units picked before the start of the game get Enhanced Infected. If this model is killed, picked models that are deployed lose the rule.
➕Enhanced ViolentIf this model has Violent, enemies always take wounds on unmodified results of 1 to block from Violent (instead of only when attacking enemies that already finished an activation).
➕Hit & Run ShooterOnce per round, this model may move by up to 3" after shooting.
➕Unpredictable FighterWhen in melee, roll one die and apply one effect to all models with this rule: on a 1-3 they get AP(+1), and on a 4-6 they get +1 to hit rolls instead.
➕VanguardAfter this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.
➖Infected BoostIf this model has Infected, when it shoots or charges enemies over 9" away, enemies taking wounds from it take extra wounds on failed defense rolls of 1-2 from Infected (instead of only on 1).
➖Infected Boost AuraThis model and up to 3 friendly units picked before the start of the game get Infected Boost. If this model is killed, picked models that are deployed lose the rule.
➖LacerateWhen attacking the target must re-roll unmodified Defense results of 6.
✏️Blast
core rule		3.5.1: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (defender picks how).
3.6.0: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (defender picks how), but each unit may only take up to as many hits as models in it
✏️Fast Aura3.5.1: This model and up to 3 friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
✏️Fortified3.5.1: When units where all models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Fortified Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get Fortified. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get Fortified. If this model is killed, picked models that are deployed lose the rule.
✏️Infected3.5.1: Enemies that roll to block hits from this model's weapons take 1 extra wound for each unmodified result of 1 that they roll.
3.6.0: When this model attacks enemies that already finished an activation this round, unmodified results of 1 to block hits from weapons deal 1 extra wound.
✏️No Retreat3.5.1: Whenever a unit where most models have this rule fails a morale test that causes it to be Shaken or Routed, the test counts as passed instead. Then, roll as many dice as the number of wounds it would take to check for wound effects (must always roll at least 1 die), and for each result of 1-3 the unit takes one wound, which can't be ignored.
3.6.0: When a unit where most models have this rule fails a Morale Test that causes it to be Shaken or Routed, the test counts as passed instead. Then, roll as many dice as the number of wounds it would take to fully destroy it, and for each result of 1-3 the unit takes one wound, which can't be ignored.
✏️No Retreat Aura3.5.1: This model and up to 3 friendly units picked before the start of the game get No Retreat. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 friendly units picked before the start of the game get No Retreat. If this model is killed, picked models that are deployed lose the rule.
✏️Precision Growth3.5.1: Place one marker on this unit at the beginning of each round if it's on the table and isn't Shaken, up to a max. of four markers. For every two markers, models with this rule in this unit get +1 to hit rolls.
3.6.0: Place one token on this unit at the beginning of each round if it's on the table and isn't Shaken, up to a max. of four tokens. For every two tokens, models with this rule in this unit get +1 to hit rolls.
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
