➕Enhanced FortifiedIf most models in this unit have Fortified, hits they take count as having AP(-2) from Fortified (instead of only AP(-1)).
➕Enhanced GuardianIf most models in this unit have Guardian, hits they take count as having AP(-2) from Guardian (instead of only AP(-1)).
➕Enhanced Guardian AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Enhanced Guardian. If this model is killed, picked models that are deployed lose the rule.
➕FortifiedWhen units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
➕Piercing FighterThis model gets AP(+1) in melee.
➕Piercing MarksmanWhen shooting at enemies over 9" away, this model's weapons get AP(+1).
➕Piercing Marksman AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Piercing Marksman. If this model is killed, picked models that are deployed lose the rule.
➕VanguardAfter this model is deployed, it may be placed anywhere fully within 9" of its position, over 9" away from non-Vanguard enemy units.
➖Guardian BoostIf all models in this unit have Guardian, enemy hits always count as having AP(-1) from Guardian (instead of only when being shot/charged from over 9" away).
➖Guardian Boost AuraThis model and up to 3 nearest friendly units picked before the start of the game get Guardian Boost. If this model is killed, picked models that are deployed lose the rule.
➖Piercing AssaultThis model gets AP(+1) when charging.
➖Piercing HunterWhen this model shoots at enemies over 9" away, its weapons get AP(+1).
➖Piercing Hunter AuraThis model and up to 3 nearest friendly units picked before the start of the game get Piercing Hunter. If this model is killed, picked models that are deployed lose the rule.
➖ReinforcedWhen units where all models have this rule are shot or charged from over 9" away and take hits, those hits count as having AP(-1), to a min. of AP(0).
➖ShieldedUnits where all models have this rule get +1 to defense rolls against hits that are not from spells.
➖TearAgainst non-Hero units with Tough(3) or more, this weapon gets AP(+4).
✏️Ambush
core rule		3.5.1: Only deploys D3 rounds afters its wave is deployed, and at the start of the round it's placed at the centre of a random table quarter.
3.6.0: Only deploys D3 rounds afters its wave, and at the start of the round it's placed within 6” of a random AI Goal.
✏️Blast
core rule		3.5.1: Ignores Cover, and after resolving other special rules, each hit is multiplied by X. Hits must be split evenly between the target and all enemy units within 3” of any model from the target (players pick how), but each unit may only take up to as many hits as models in it.
3.6.0: Ignores cover, and after resolving other special rules, each hit is multiplied by X, where X is up to as many hits as enemy models in the target unit and within 3” of it. Hits must be split evenly between all enemy units within 3” of any model from the target (players pick how).
✏️Disintegrate3.5.1: Ignores Regeneration, and against units where most models have Defense 2+ to Defense 3+, this weapon gets AP(+2).
3.6.0: Ignores Regeneration, and when attacking units where most models have Tough(27) or higher, this weapon gets AP(+2).
✏️Fast Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game moves +2" when using Advance actions and +4" when using Rush/Charge actions. If this model is killed, picked models that are deployed lose the rule.
✏️Guardian3.5.1: When units where all models have this rule are shot or charged from over 9" away and take hits, those hits count as having AP(-1), to a min. of AP(0).
3.6.0: When units where most models have this rule take hits, those hits count as having AP(-1), to a min. of AP(0).
✏️Piercing Target3.5.1: Once per game, during this model's activation, pick one enemy unit within 18" and in line of sight of it, and place X markers on it. Friendly units get +AP(X) on their weapons when attacking it.
3.6.0: Once per game, during this model's activation, pick X enemy units within 18" and in line of sight of it, and place one token on them. Friendly units get AP(+1) on their weapons when attacking them.
✏️Quick Shot Mark3.5.1: Once per activation, before attacking, pick up to 4 enemy units within 18" in line of sight, which friendly units gets Quick Shot against once (next time the effect would apply).
3.6.0: Once per activation, before attacking, pick up to 3 enemy units within 18" in line of sight, which friendly units gets Quick Shot against once (next time the effect would apply).
✏️Regeneration
core rule		3.5.1: When a unit where all models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
3.6.0: When a unit where most models have this rule takes wounds, roll one die for each. On a 5+ it is ignored.
✏️Shred
becomes a core rule		3.5.1: On unmodified results of 1 to block hits, this weapon deals 1 extra wound.
3.6.0: For each unmodified result of 1 to block hits, this weapon deals 1 extra wound.
✏️Shred in Melee Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Shred in melee. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Shred in melee. If this model is killed, picked models that are deployed lose the rule.
✏️Stealth
core rule		3.5.1: When units where all models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
3.6.0: When units where most models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
✏️Stealth Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule.
