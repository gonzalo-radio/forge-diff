Special rules

NameText
➕Enhanced GuardedIf most models in this unit have Guarded, they always get +1 to Defense rolls from Guarded (instead of only the first time they are attacked each round).
➕Enhanced TenaciousIf most models in this unit have Tenacious, they always get +1 to Defense rolls from Tenacious (instead of only the first time they are attacked each round).
➕Enhanced Tenacious AuraThis model's unit and up to 2 nearest friendly units picked before the start of the game get Enhanced Tenacious. If this model is killed, picked models that are deployed lose the rule.
➕ObliterateIgnores Regeneration, and when attacking units where most models have Tough(27) or higher, the target must re-roll successful unmodified Defense results of 5-6.
➖ShredOn unmodified results of 1 to block hits, this weapon deals 1 extra wound.
➖Tenacious BoostIf all models in this unit have Tenacious, they always get +1 to defense rolls from Tenacious (instead of only when being shot/charged from over 9" away).
➖Tenacious Boost AuraThis model and up to 3 nearest friendly units picked before the start of the game get Tenacious Boost. If this model is killed, picked models that are deployed lose the rule.
✏️Ambush
core rule		3.5.1: Only deploys D3 rounds afters its wave is deployed, and at the start of the round it's placed at the centre of a random table quarter.
3.6.0: Only deploys D3 rounds afters its wave, and at the start of the round it's placed within 6” of a random AI Goal.
✏️Furious
core rule		3.5.1: When charging, unmodified results of 6 to hit in melee deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When charging, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Furious Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Furious. If this model is killed, picked models that are deployed lose the rule.
✏️Guarded3.5.1: When units where all models have this rule are shot or charged from over 9" away, they get +1 to defense rolls.
3.6.0: If most models in this unit have this rule, the first time they are attacked each round, they get +1 to Defense rolls.
✏️Indirect
core rule		3.5.1: Gets -1 to hit rolls when shooting after moving. May target enemies that are not in line of sight as if in line of sight, and ignores cover from sight obstructions.
3.6.0: When using Hold actions and shooting, may target enemies that are not in line of sight as if in line of sight, and ignores Cover from Sight Blockers.
✏️Indirect when Shooting Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Indirect when shooting. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Indirect when shooting. If this model is killed, picked models that are deployed lose the rule.
✏️Precision Frenzy3.5.1: Place one marker on this unit when it fully destroys an enemy unit, up to a max. of two markers. For each marker all models with this rule in this unit get +1 to hit rolls until the end of the game.
3.6.0: Place one token on this unit when it fully destroys an enemy unit, up to a max. of two tokens. For each token all models with this rule in this unit get +1 to hit rolls until the end of the game.
✏️Relentless
core rule		3.5.1: When this model shoots at enemies over 9" away, unmodified results of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
3.6.0: When this model shoots at enemies over 9” away, unmodified result of 6 to hit deal 1 extra hit (only the original hit counts as a 6 for special rules).
✏️Relentless Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Relentless. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Relentless. If this model is killed, picked models that are deployed lose the rule.
✏️Stealth
core rule		3.5.1: When units where all models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
3.6.0: When units where most models have this rule are shot from over 9" away, enemy units get -1 to hit rolls.
✏️Stealth Aura3.5.1: This model and up to 3 nearest friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule.
3.6.0: This model's unit and up to 2 nearest friendly units picked before the start of the game get Stealth. If this model is killed, picked models that are deployed lose the rule.
